# Python List Analyzer

A beginner-friendly Python mini project that performs multiple operations and analyses on a user-provided list of integers.

This project was created to practice Python fundamentals such as loops, conditional statements, lists, arithmetic operations, and problem-solving logic.

## Features

The program performs the following operations:

* Calculates the length of the list without using `len()`
* Calculates the sum of all elements
* Searches for a user-provided value
* Counts the frequency of the searched value
* Finds the highest value
* Finds the second highest value
* Finds the lowest value
* Finds the second lowest value
* Separates even and odd numbers
* Counts even and odd numbers
* Calculates the sum of even and odd numbers
* Identifies prime and non-prime numbers
* Counts prime and non-prime numbers
* Calculates the sum of prime and non-prime numbers
* Identifies palindrome numbers
* Counts palindrome and non-palindrome numbers
* Calculates the sum of palindrome and non-palindrome numbers
* Identifies Armstrong numbers
* Counts Armstrong and non-Armstrong numbers
* Calculates the sum of Armstrong and non-Armstrong numbers
* Calculates the factorial of each number
* Calculates the sum of all factorial values
* Sorts the list in ascending order
* Sorts the list in descending order

## Input

The user enters comma-separated integer values.

Example:

```text
Enter comma separated values: 3,4,5,6,11,121,153
```

The user then enters a value to search:

```text
Enter the value you want to search: 5
```
